# Frontend

Le frontend React/Vite de Maintenance Piscine est documenté dans le README principal du dépôt :

[Consulter la documentation complète](../README.md)

## Commandes locales

```bash
npm install
npm run dev
```

Contrôles et build de production :

```bash
npm run lint
npm run build
npm run preview
```

La configuration locale utilise `VITE_API_URL` pour l'URL de l'API et `VITE_API_KEY` pour la clé envoyée dans `X-API-KEY`. Voir la section Configuration du README principal.
